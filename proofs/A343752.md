# A343752: the sequence returns to n exactly at the triangular numbers

## Statement

OEIS [A343752](https://oeis.org/A343752) is defined by a(1) = 1 and, for
n > 1,

- a(n) = n if n divides a(n-1),
- a(n) = a(n-1) + n otherwise.

Its formula section says:

> Apparently, a(n) = n iff n belongs to A000217.

A000217 is the sequence of triangular numbers $T_k = k(k+1)/2$. Status on
2026-11-26: listed as an observation without proof (since 2021).

**Theorem.** For every $n \ge 1$, $a(n) = n$ if and only if $n = T_k$ for
some $k \ge 1$. More precisely, for all $k \ge 1$ and $0 \le j \le k$,

```math
a(T_k + j) = (j+1)\,T_k + T_j .
```

Every $n \ge 1$ has a unique representation $n = T_k + j$ with $k \ge 1$ and
$0 \le j \le k$, so this is a closed form for the whole sequence.

## Prior work

"Apparently". The entry has no reference and no link other than its own
b-file. A literature search found no proof. The proof below is an elementary

## Proof

We prove by induction on $k \ge 1$ that $a(T_k) = T_k$, and along the way the
closed form on the block $T_k, T_k + 1, \dots, T_k + k$.

**Base.** $a(T_1) = a(1) = 1$.

**Block.** Assume $a(T_k) = T_k$. We show $a(T_k + j) = (j+1) T_k + T_j$ for
$0 \le j \le k$ by induction on $j$. The case $j = 0$ is the assumption. Let
$j + 1 \le k$ and put $n = T_k + j + 1$. Using $T_j + T_{j+1} = (j+1)^2$,

```math
a(n-1) + T_{j+1} = (j+1)\,T_k + T_j + T_{j+1} = (j+1)\,n .
```

So n divides $a(n-1)$ if and only if n divides $T_{j+1}$. But
$0 < T_{j+1} \le T_k < n$, so n does not divide $a(n-1)$, and

```math
a(n) = a(n-1) + n = (j+2)\,T_k + T_j + (j+1) = (j+2)\,T_k + T_{j+1} .
```

**Return.** Let $n = T_{k+1} = T_k + k + 1$. By the block formula with
$j = k$ and $2T_k = k(k+1)$,

```math
a(n-1) = (k+2)\,T_k = k\,T_k + k(k+1) = k\,(T_k + k + 1) = k\,n ,
```

so n divides $a(n-1)$ and $a(T_{k+1}) = T_{k+1}$. This completes the
induction.

**Converse.** If n is not triangular then $n = T_k + j$ with
$1 \le j \le k$, and

```math
a(n) - n = j\,T_k + T_j - j \ge j + 1 - j > 0 ,
```

because $T_k \ge 1$ and $T_j \ge 1$. Hence $a(n) \ne n$. $\blacksquare$

## Formalization

`OeisProofs/A343752.lean` contains a complete Lean 4 proof. The final theorem
is

```lean
theorem a_eq_self_iff {n : Nat} (hn : 1 <= n) :
    a n = n <-> exists k, n = k * (k + 1) / 2
```

where `a` is defined by the OEIS recurrence (with a placeholder value at
index 0) and `/` is natural-number division, which is exact here. The proof
depends only on the standard axioms `propext`, `Classical.choice` and
`Quot.sound`. The block formula is `a_block`. The theorem `a_data` is a
kernel-checked proof that the definition reproduces the first 16 terms listed
in the OEIS.
